# Toko Buku Online

## Deskripsi
Toko Buku Online merupakan aplikasi berbasis website sederhana yang dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web 1.

Website ini digunakan untuk menampilkan katalog buku, mengelola stok, melakukan pemesanan buku, serta melihat informasi pelacakan pengiriman.

## Fitur Website
1. **Login**  
   Digunakan untuk masuk ke dalam aplikasi menggunakan email dan password.

2. **Dashboard**  
   Menampilkan halaman utama dan menu navigasi website.

3. **Katalog Buku dan Stok**  
   Menampilkan daftar buku beserta kode barang, nama buku, jenis buku, edisi, harga, dan stok.

4. **Checkout / Pemesanan**  
   Digunakan untuk memilih buku, memasukkan jumlah pesanan, menghitung total harga, dan menyimpan transaksi sementara.

5. **Tracking Pengiriman**  
   Digunakan untuk mencari informasi status pengiriman berdasarkan nomor Delivery Order (DO).

## Teknologi yang Digunakan
- HTML5
- CSS3
- JavaScript
- JavaScript DOM

## Cara Menjalankan Website
1. Buka folder project menggunakan Visual Studio Code.
2. Pastikan seluruh file HTML, CSS, JavaScript, dan gambar sudah berada di folder yang sesuai.
3. Jalankan file `index.html` menggunakan Live Server.
4. Masukkan akun untuk login.
